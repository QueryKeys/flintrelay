# FlintRelay brand assets

The primary horizontal logo combines a flint-shaped routing mark with the FlintRelay wordmark. The selected route uses an ember-orange accent.

| File | Use |
| --- | --- |
| `flintrelay-logo.png` | Transparent PNG with a dark foreground for light backgrounds |
| `flintrelay-logo-dark.png` | Ivory-white foreground on an opaque dark background for GitHub dark mode |

Both assets are raster PNGs, 2172 × 724 pixels. They are not editable SVGs. The root English and Hebrew READMEs select the appropriate asset using a `picture` element and the visitor's color-scheme preference. Both include descriptive alternative text.

Generated with the built-in Imagegen tool. The final prompts are recorded in `generation-prompt.txt` and `generation-prompt-dark.txt`. Keep the symbol and wordmark together, preserve the aspect ratio, and choose an asset that remains readable on its background.
