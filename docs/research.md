# Research and design rationale

Research completed 2026-10-07 before implementation. This page summarizes the evidence without local account details or raw sessions.

## Native integration

Claude Code Mods expose a native per-step interception point. The preview modifies only a permitted model field and forwards the original stream exactly once. It keeps the existing authentication, native account restrictions, tool permissions, and request path. A gateway or classifier model request would add another transport and cost without being necessary for this first scope.

Primary documentation: [Mods overview](https://code.claude.com/docs/en/plugins/mods/overview), [native reference](https://code.claude.com/docs/en/plugins/mods/reference), [offline testing](https://code.claude.com/docs/en/plugins/mods/test), [usage](https://code.claude.com/docs/en/costs), [marketplaces](https://code.claude.com/docs/en/plugin-marketplaces).

The documented stable CLI floor is 2.1.287, but this preview grants active routing only on exact tested CLI 2.1.290. Public declarations available during development were generated by 2.1.277; offline host validation/testing is the stronger exercised contract. The exposed skill event has no turn identifier, so skill provenance is protected conservatively. Manual model switches revoke ownership.

## Quality and cost

Routing must compare full task outcomes and full observed request cost against a simple baseline that already meets the same quality threshold. Cache usage, retries, failures and escalations matter. A subscription allowance is not interchangeable with API dollars. These principles informed separate token counters, unknown-usage disclosure, and disabled automatic downgrades.

Primary research: [RouteLLM](https://arxiv.org/abs/2406.18665), [RouterBench](https://arxiv.org/abs/2403.12031), [FrugalGPT](https://arxiv.org/abs/2305.05176).

The initial deterministic classifier is an advisory bilingual heuristic, not a calibrated model-quality predictor. Eight task strata have acceptance definitions in `evaluation/cases.json`; these are not completed inference evaluations. Any future trial must separate calibration from held-out task/repository families, predeclare a budget and stop conditions, and test non-inferior quality before considering lower-cost automatic choices.

## Preview decisions

Shadow is the default. Active is an explicit session grant and promotes only. Unknown or extended-context IDs and advanced/numeric effort abstain. Subagents pass through. Classification incurs no auxiliary inference. Persistence defaults off and saves category counts/coverage rather than task content or historical token totals. End-to-end quality, savings, entitlement and inference latency remain unmeasured.
