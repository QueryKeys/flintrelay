# Research and design rationale

Research completed 2026-10-07 before implementation. This page summarizes the evidence without local account details or raw sessions.

## Native integration

Claude Code Mods expose a native per-step interception point. The preview modifies only the permitted model and effort fields and forwards the original stream exactly once. It keeps the existing authentication, native account restrictions, tool permissions, and request path. A gateway or classifier model request would add another transport and cost without being necessary for this first scope.

Primary documentation: [Mods overview](https://code.claude.com/docs/en/plugins/mods/overview), [native reference](https://code.claude.com/docs/en/plugins/mods/reference), [offline testing](https://code.claude.com/docs/en/plugins/mods/test), [usage](https://code.claude.com/docs/en/costs), [marketplaces](https://code.claude.com/docs/en/plugin-marketplaces).

The documented stable CLI floor is 2.1.287, but preview 0.2.0 grants active routing only on exact tested engines 2.1.286 and 2.1.290. The macOS Desktop app was observed to embed 2.1.286 independently of the terminal installation; its native offline matrix was exercised before admission. Public declarations available during development were generated by 2.1.277; offline host validation/testing is the stronger exercised contract. The exposed skill event has no turn identifier, so skill provenance is protected conservatively. Manual model switches revoke ownership.

## Quality and cost

Routing must compare full task outcomes and full observed request cost against a simple baseline that already meets the same quality threshold. Cache usage, retries, failures and escalations matter. A subscription allowance is not interchangeable with API dollars. These principles informed separate token counters, unknown-usage disclosure, and disabled automatic model downgrades.

Primary research: [RouteLLM](https://arxiv.org/abs/2406.18665), [RouterBench](https://arxiv.org/abs/2403.12031), [FrugalGPT](https://arxiv.org/abs/2305.05176).

The initial deterministic classifier is an advisory bilingual heuristic, not a calibrated model-quality predictor. Eight task strata have acceptance definitions in `evaluation/cases.json`; these are not completed inference evaluations. Any future trial must separate calibration from held-out task/repository families, predeclare a budget and stop conditions, and test non-inferior quality before considering lower-cost automatic choices.

## Preview decisions

Shadow is the default. Active is an explicit session grant and promotes only. Unknown or extended-context IDs abstain. Auto effort may replace advanced string levels; preserve mode and numeric budgets retain compatibility abstention. Subagents pass through. Classification incurs no auxiliary inference. Persistence defaults off and saves category counts/coverage rather than task content or historical token totals. End-to-end quality, savings, entitlement and inference latency remain unmeasured.

## Per-task effort research — 0.2.0

Primary sources checked on 2026-10-07: [Claude Code model configuration](https://code.claude.com/docs/en/model-config), [API effort](https://platform.claude.com/docs/en/build-with-claude/effort), [Mod events](https://code.claude.com/docs/en/plugins/mods/events). Effort support differs by model, provider and host. Recent Opus/Sonnet models support `xhigh`; 4.6 models do not. Aliases can resolve to older or pinned models, so promotion aliases receive only common levels. Haiku 5.5 requires a newer host than those tested here. A higher effort is a larger compute budget, not proof of quality, and can affect caching.

The native `turn.step` contract permits model/effort rewrites and pins the request identity, index, message count and agent. It has no effort-origin or executed-effort field. Bounded inspection of the installed official 2.1.286 and 2.1.290 executables confirmed that changed hook effort is passed to the native effort resolver, which applies model compatibility and configured/organization ceilings. This is implementation evidence for these exact hosts; the offline stream harness does not itself exercise provider inference or organization policy enforcement.

A bilingual deterministic effort classifier runs separately from the model floor, applies the highest recognized complexity category, and keeps incoming effort for ambiguous tasks. Full automatic mode can replace a saved `xhigh`, as explicitly requested for this installation. Native `/effort` commands establish session preserve mode. Startup flags/environment provenance is unavailable; the documented preserve option is the explicit override. Neither native settings nor environment/credentials are inspected or rewritten by the runtime.
