# Security

## Supported scope

Version 0.1.0 is a preview tested with exact CLI 2.1.290. Account entitlement, native cancellation, undocumented event ordering and live quality are not certified. Other hosts do not receive active support automatically.

## Reporting

For a non-sensitive bug, open a GitHub issue with a minimal sanitized reproduction. For a vulnerability containing sensitive details, use GitHub's private vulnerability reporting if the repository exposes it. If that option is unavailable, open an issue requesting a private reporting channel without exploit details, tokens, private paths or source. Do not post credentials publicly.

The router must not approve tools, weaken permissions, bypass account restrictions or add a second inference request after a stream error. Regressions in these boundaries require a failing behavioral test before a fix. Existing repository/process security hooks remain authoritative.
